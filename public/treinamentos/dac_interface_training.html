Quatro Interfaces, Quatro Modelos de Serviço
Cada interface corresponde a um modelo de serviço de restaurante. Entender a analogia ajuda você a escolher a certa instantaneamente.
🚚
FlightHub Sync
"Entrega de cardápio fixo — diga o endereço e entregamos automaticamente"
Ponte de dados configurada pela interface gráfica. Encaminhamento de livestream, envio de telemetria MQTT e sincronização de arquivos S3 — tudo sem escrever uma única linha de código.
Sem Código
👨‍🍳
Open API
"Linha da cozinha privada — chame a cozinha diretamente, controle o que acontece"
Interface HTTP RESTful. Dispare livestreams, envie missões, consulte o estado dos dispositivos, gerencie recursos — controle programático bidirecional completo.
Requer Dev
🔔
Event API
"Garçom proativo — no momento em que o prato fica pronto, ele vem te avisar"
Envio via webhook HTTP. A FH2 envia notificações POST ao seu endpoint quando ocorrem eventos — missão concluída, mídia pronta, anomalia de dispositivo. Sem polling.
Requer Dev
🏪
Componentes Frontend
"Alugue a cozinha profissional — seu espaço, seus equipamentos e chefs"
Incorpore os módulos UI testados em produção da FH2 (Virtual Cockpit, Route Editor, Map) diretamente à sua plataforma via paas.js. Somente On-Premises.
Somente On-Prem
